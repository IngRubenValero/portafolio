Criterio para la portada

La portada va a sangre con un desvanecimiento oscuro de izquierda a derecha y el titular encima. Conviene dejar el motivo a la derecha y la zona izquierda oscura o despejada. Se recomienda una imagen horizontal de al menos 1600 px de ancho. El panel la limita a 2400 px y la convierte a WebP calidad 82.

  1. Conectar «Carpeta del proyecto» (la raíz con data/ e img/)
  2. Subir la imagen o guardar una ruta existente
  3. Ejecutar python tools/validar.py y bash publicar.sh

Opción 1 · Windows (recomendada)

Haz doble clic en publicar.bat, en la raíz del proyecto. Abre Git Bash, ejecuta la validación y sube los cambios. Al terminar deja la ventana abierta con el resultado.

publicar.bat

Opción 2 · Git Bash

Desde la raíz del proyecto:

python tools/validar.py
bash publicar.sh

Qué hace publicar.sh

  1. Valida rutas, esquema y data/site.json / data/content.json; si algo falla, no hace commit.
  2. Conserva el historial remoto y guarda el estado anterior en la rama local respaldo/sitio-anterior.
  3. Hace commit y push normal, sin --force.
  4. GitHub Pages reconstruye el sitio en 1–2 minutos.

La primera vez Git puede pedir credenciales (Git Credential Manager o un token personal). No hay contraseñas guardadas en el proyecto.
